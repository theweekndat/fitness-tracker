# Decisions

Changes to assumptions in `docs/BRIEF.md`, newest first. Each entry: date, what changed, why.

## 2026-10-11

- **Deploy via Cloudflare Workers Builds (Git integration)**, not a local `wrangler deploy`. There is no Mac,
  and this keeps the Cloudflare API token and all secrets out of the build environment. Secrets go in the
  dashboard.
- **OFF_CONTACT = `github.com/theweekndat`**. Not the user's email.
- **Open Food Facts cache in KV, not the Cache API.** The Cache API is a no-op on `*.workers.dev`
  (brief §3 says to use the Cache API). See PHASE0_FINDINGS §1.
- **VAPID keys are generated by the Worker and stored in KV** instead of being a hand-set secret.
  One less manual step; the key never leaves Cloudflare.
- **The Phase 0 spike uses the OFF v2 product endpoint** (`/api/v2/product/{code}.json?fields=…`).
  Moving to v3 waits until the docs can be read.
- **The upstream network failure maps to `502 upstream_unreachable`**, so the app can tell "Open Food Facts
  down" from "product not found". Outages are excluded from the barcode hit rate.
- **A4 to A7 accepted as the brief's defaults** pending the user's confirmation: protein band 1.5 to 2.0 g/kg,
  activity bar = active calories (+ exercise minutes), metric units, Oura-only steps.
- **Proposed for Phase 1 (not yet applied):** round protein and fat to whole grams, then derive carbs; the
  macro property test allows ±5 kcal after rounding.
